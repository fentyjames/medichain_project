    About Zero-Knowledge Proofs
    zk-SNARKs

    Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge provide efficient verification with small proof sizes. Used for transaction batch verification in Layer-2 rollups.

    • Proof size: ~200 bytes
    • Verification time: ~50ms
    • Trusted setup required
    Use Cases
    • Patient Identity: Verify without revealing personal data
    • Lab Results: Confirm thresholds without exact values
    • Insurance Claims: Validate without disclosing history
    • Prescriptions: Authenticate without diagnosis details
